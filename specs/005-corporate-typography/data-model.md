# Data Model

No introduce datos ni cambios de esquema. Estructuras del tema:

- **fonts** (tokens): `regular`, `semibold`, `bold` (cuerpo, Source Sans 3 400, 600 y 700 hoy; Myriad Pro después) y `mono` (Source Code Pro 400). Único lugar con nombres de fuente.
- **typography** (estilos): `screenTitle` 26/32 Bold, `sectionTitle` 19/26 Semibold, `cardTitle` 17/22 Semibold, `metricNumber` 30/36 Bold, `body` 15/22 Regular, `bodySmall` 13/18 Regular, `metadata` 13/18 Regular, `label` 12/16 Semibold (espaciado 0,24), `button` 15/20 Semibold, `code` 14/20 Regular (mono).
