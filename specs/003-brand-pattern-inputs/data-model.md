# Data Model

No introduce datos persistentes ni cambios de esquema. Estructuras de UI:

- **PatternPlacement**: `x` (%), `y` (%), `size` (30 a 64 px), `rotation` (-30° a 30°), `icon` (`leaf`, `feather` u `openBook`), `tone` (`white` o `lime`). Lista fija por variante (`header`: 14, `hero`: 3).
- **Tokens de campo** (derivados de `Design.md`): `inputFill`, `inputBorder` (#C9D0C3), `inputBorderFocus` (#4E7A2F), con equivalentes en modo oscuro.
